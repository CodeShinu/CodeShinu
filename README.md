## Projetos

### [`projetokc-api`](https://github.com/CodeShinu/projetokc-api)

API REST que estou construindo com **Python + Flask** para estudar backend na prática.

```text
GET   /             status da API
GET   /tasks        lista as tarefas
POST  /tasks        cria uma nova tarefa
```

O projeto ainda está evoluindo. Os próximos passos são persistência com SQLite, operações de atualização e exclusão, validações e testes.
